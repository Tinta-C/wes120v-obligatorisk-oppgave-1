# Studentguiden - WES120v
Dette er en nettsidide for studentguiden, utarbeidet som en av laboppgaven i WES120v. prosjektet er bygget med HTML5 og Vite.
## Krav for å kjøre prosjektet
For å kjøre prosjektet lokalt må du ha følgende installert på din maskin:
* **Node.js**
* **pnpm**
## Slik kjører du prosjektet lokalt
1. Installer avhengigheter (hvis det ikke allerede er gjort):
```bash
pnpm install
